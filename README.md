# Velcode — backend (этап 1)

FastAPI + SQLAlchemy (async) + SQLite (по умолчанию, легко переключить на Postgres через `DATABASE_URL`).

## Запуск

```bash
pip install -r requirements.txt
python -m scripts.seed "Прайс-лист услуг компании.xlsx"   # разово наполняет БД из вашей таблицы
uvicorn app.main:app --reload
```

Открыть http://127.0.0.1:8000/docs — автогенерируемая Swagger-документация по всем эндпоинтам.

## Что уже есть

- `GET /api/categories` — разделы услуг
- `GET /api/services` (+`?category_id=`) — услуги, у каждой сразу все её разделы (услуга может
  входить в несколько разделов — так устроено в вашем прайсе, например "Разработка сайта под
  ключ" числится и в "Веб-разработке", и в служебном разделе "Под ключ")
- `GET /api/faq` — вопросы-ответы
- `POST /api/leads` — приём заявки (форма на сайте шлёт сюда AJAX без перезагрузки страницы);
  валидация имени/телефона/чекбокса согласия задублирована на бэкенде — не полагаемся только на
  JS на фронте
- `app/notifications.py: notify_new_lead()` — заглушка уведомления о новой заявке (сейчас просто
  пишет в лог). Реальный канал (email / Telegram-бот / сразу в Битрикс24 через API) подключим
  отдельно, когда решите какой

## Что сознательно не делали на этом этапе

- Вёрстку/шаблоны — дизайн новых страниц ещё не готов, отдаём чистый JSON API
- Alembic-миграции — таблицы создаются автоматически при старте (`init_models()`); когда схема
  устаканится, добавим настоящие миграции
- Админку для правки текстов без кода — при желании можно навесить SQLAdmin поверх тех же моделей
  почти без переделок
