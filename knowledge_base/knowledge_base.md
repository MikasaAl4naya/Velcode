### Парсер лидов с интеграцией в Битрикс24
Кейс / Проект: Парсер лидов с интеграцией в Битрикс24
Ссылка: /portfolio/parser-lidov-bitriks24
Теги: Python, Telegram, Автоматизация, Битрикс24, Парсинг
Описание: Бот-парсер автоматически мониторит Telegram-каналы с заказами и Kwork.ru, отфильтровывает нужные проекты и сразу создаёт лиды в Битрикс24 — без ручной работы.
Что было сделано: Сервис на Python, который в фоновом режиме по расписанию парсит два источника: Telegram-каналы через Telethon userbot и Kwork.ru через JSON API сайта. Новые сообщения и проекты проходят фильтр релевантности — ключевые слова и стоп-слова задаются в конфиге, без правки кода.

Дедупликация через content_hash: один и тот же заказ из разных каналов не создаст несколько лидов.

Парсер автоматически извлекает бюджет из текста: понимает форматы «5000–15000 ₽», «бюджет: 30к», «от 50 USD». Каждый лид приходит в Битрикс24 с проставленным источником (отдельный UC_-тег для Telegram и для Kwork) и суммой сделки.

Отправка в CRM батчами: до 50 лидов за один HTTP-запрос через batch-эндпоинт. Если запрос упал — сервис помечает лиды и повторяет их при следующем цикле.

Управление каналами прямо из Telegram: команды /add, /del, /pause, /resume — добавлять или останавливать каналы без перезапуска сервиса. Деплой через Docker Compose.
